# GTI SYN管理ツール

WordPress テーマ **「賢威8」** から **「SYN（SYNオウンド）」** への移行・管理を支援するための管理ツールです。  
PV統合、TOC（目次）自動挿入、アイキャッチ表示移行、メニュー検索追加など、移行時の作業を簡略化するための機能をまとめています。

---

## 📢 【重要】アップデート配信元の移行とGitHub閉鎖について（Ver 1.7.0以降）

本バージョン（Ver 1.7.0）より、セキュリティ向上およびサービス向上のため、プラグインの自動アップデートシステムを **GitHub から弊社自社サーバー（gti.co.jp）経由の配信へ完全移行**いたしました。

これに伴い、**2026年10月中旬をもってGitHub上のリポジトリおよびGitHub経由のアップデート配信は終了（閉鎖）**いたします。

今後も自動アップデートを安全に受け取るために、以下の手順で移行手続きをお願いいたします。

1. 本バージョン（Ver 1.7.0）へアップデートします。（※これがGitHubから配信される最後のバージョンとなります）
2. プラグインのダッシュボードに新設された **「基本設定」** カードより、**「ウェブサポーターズ APIキー」** を入力し、保存してください。
3. APIキーが正しく登録されることで、次回以降のアップデート（Ver 1.7.1以降）が自社サーバーから自動配信されるようになります。

## 🧰 主な機能（追加新着順）

### ✅ メニュー検索追加機能（PC/SP個別設定対応）【v1.7.0】
- **テーマを汚さない自動挿入**:
  これまで子テーマ（`syn-ownd-child`）のテンプレートファイルを直接上書き・編集していた「PC用グローバルナビの右端への検索窓追加」および「スマホ用ドロワーメニューの末尾への検索窓追加」をプラグイン側から自動でフック挿入します。
- **個別ON/OFF切り替え**:
  管理画面「メニュー内検索設定」より、PC表示時とスマホ表示時のそれぞれの検索窓の表示・非表示を個別にオンオフできます。
- **専用CSS自動適用**:
  レイアウト調整用のCSSもプラグイン側から自動適用されるため、テーマアップデートの影響を一切受けずに美しいレイアウトを維持できます。

---

### ✅ Blogcard拡張機能【v1.6.0】
- `[blogcard]` ショートコードで `target` 属性のサポートを追加します。
- `[blogcard url="https://example.com" target="_self"]` のように指定可能です。
- `target="_blank"`（新しいタブ）/ `target="_self"`（同じタブ）を選択可能です。
- 管理画面で ON/OFF 切り替え可能です。

---

### ✅ 抜粋表示（JavaScript挿入）機能【v1.6.0】
- 記事一覧ページで、どのレイアウトタイプでも抜粋を動的に表示します。
- カード型、リスト型、サムネイル型など、すべてのレイアウトで抜粋表示を実現します。
- PC表示時の抜粋文字数を設定可能です（デフォルト120文字、モバイルは自動的に80%に調整）。
- 管理画面で ON/OFF 切り替え可能です。

---

### ✅ 賢威ボックス互換レイヤー【v1.5.0】
- 賢威8 で使用されていたボックススタイル（`.box_style` 等）を、SYN OWND のデザインに合わせて装飾します。
- 既存記事の表示崩れを防止し、HTMLはそのままでCSSのみを適用してデザインを整えます。
- ブロックパターン「GTI 賢威→SYN 互換」をエディターに追加します。
- 子テーマに `gti-keni-tools/box-style-compat.css` を配置することで上書き可能です。

---

### ✅ 期間別ランキング機能【v1.4.0】
週間・月間・全期間のアクセスランキングを表示するウィジェットを追加します。
- **ウィジェット「【GTI】期間別ランキング」**
  - 集計期間（週間・月間・全期間）を選択可能
  - カテゴリー絞り込み（指定カテゴリー / 現在のカテゴリー）
  - 0 view の記事を除外するオプション
  - SYN OWND テーマのデザインを継承（リスト型、カード型など）
- **管理画面で ON/OFF 切り替え可能**

---

### ✅ 賢威ショートコード互換機能【v1.3.0】
賢威テーマで使用していたショートコードを SYN テーマでもそのまま利用可能にします。
- `[keni-linkcard]` を `[blogcard]` に自動変換します。
- `[cc id="123"]` 共通コンテンツショートコードに対応します。
- functions.php との競合を回避し、管理画面で機能の ON/OFF 切り替え可能です。

---

### ✅ アイキャッチポリシー移行ツール（賢威 → SYN）【v1.2.0】
賢威8 と SYN ではアイキャッチ表示仕様が異なるため、過去記事のアイキャッチ表示状態を正しく移行するための一括変換ツールです。
- **変換ルール**: 賢威の個別設定 `keni_thumbnail_disp_post` および全体設定 `keni_thumbnail_disp` を読み取り、SYN の `_synx_eyecatch` に変換
- **Dry-run**: 対象件数や更新件数の確認、記事ごとの変換結果一覧表示が可能
- **実行モード**: `_synx_eyecatch = 1`（非表示）を安全に一括セット（すでに設定済みの記事は自動スキップ）

---

### ✅ SYN TOC（目次）自動挿入機能【v1.1.0】
- 記事本文に `[synx_toc]` が無い場合、自動的に TOC を生成します。
- 管理画面「賢威-SYNツール」配下に設定画面を用意しています。
- 設定可能項目
  - TOC の自動表示 ON / OFF  
  - 挿入位置（タイトル直下 / 最初の H2 の前）  
  - 見出しレベル（H2〜H4）

---

### ✅ PV統合ツール【v1.0.0】
- 賢威テーマで保持していた PV カウントデータを SYN に統合します。
- Dry-run（件数確認）＋バッチ処理による安全な移行に対応しています。

## 💡 インストール方法

### 方法1: WordPressアップロードインストール（推奨）

1. **ZIPファイルをダウンロード**
   - ※2026年10月中旬までは[GitHubリリースページ](https://github.com/taman777/gti-keni-tools/releases)からVer 1.7.0をダウンロードできます。
   - それ以降は、弊社ウェブサポーターズ公式サイトより最新のパッケージをダウンロードしてください。
   
2. **WordPressにアップロード**
   - WordPress 管理画面 → **プラグイン → 新規追加 → プラグインのアップロード**
   - ダウンロードした `gti-keni-tools.zip` を選択してアップロード
   - **今すぐインストール** をクリック
   
3. **有効化**
   - インストール完了後、**プラグインを有効化** をクリック
   
4. **APIキーの設定（必須）**
   - メニュー **「賢威-SYNツール」** （または設定のトップ画面）を開き、「基本設定」にて **「ウェブサポーターズ APIキー」** を入力・保存してください。

## 🎯 使い方（追加新着順）

メニュー **「賢威-SYNツール」** から各機能を利用できます：
- **メニュー内検索設定** - PC/スマホ用メニューへの検索窓追加（v1.7.0）
- **Blogcard拡張** - blogcardショートコードの target 属性サポート（v1.6.0）
- **抜粋表示（JS挿入）** - 記事一覧への抜粋動的挿入（v1.6.0）
- **賢威BOXスタイル** - ボックス互換レイヤーの有効化（v1.5.0）
- **期間別ランキング** - ランキングウィジェットの有効化（v1.4.0）
- **ショートコード互換** - 賢威ショートコードの互換性（v1.3.0）
- **アイキャッチ移行** - アイキャッチポリシー移行ツール（v1.2.0）
- **SYN目次設定** - 目次の自動挿入設定（v1.1.0）
- **PV統合ツール** - 賢威のPVデータをSYNに統合（v1.0.0）
- **強制抜粋表示（非推奨）** - 旧「抜粋強制表示」設定画面（非推奨・非動作）
